# Space Tourism App: Vue 3 + Laravel 12

## Frontend (Vue)
Located in `/frontend/`

## Backend (Laravel)
Located in `/backend/`

## Development Setup
- `cd frontend && npm install && npm run dev`
- `cd backend && composer install && php artisan serve`
